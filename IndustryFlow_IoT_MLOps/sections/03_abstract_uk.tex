\chapter*{АНОТАЦІЯ}
\addcontentsline{toc}{chapter}{АНОТАЦІЯ}

У роботі представлено методологію розробки платформи IoT MLOps для моніторингу промислових сенсорів у реальному часі з виявленням аномалій на основі машинного навчання. Підхід поєднує потокову обробку даних через Apache Kafka та Apache Spark Structured Streaming з мультитенантною архітектурою схема-на-тенанта в TimescaleDB. Система використовує алгоритми детекції аномалій з інфраструктурою MLflow для відстеження експериментів та версіонування моделей. Експериментальні результати демонструють ефективність потокової обробки, стиснення даних та якість детекції аномалій на бенчмарковому наборі даних. Робота надає готове рішення для промислових підприємств, що забезпечує раннє виявлення несправностей обладнання на базі технологій з відкритим кодом.

Ключові слова: IoT, MLOps, виявлення аномалій, промисловий моніторинг, TimescaleDB, Apache Kafka, Apache Spark, машинне навчання, мікросервісна архітектура.
