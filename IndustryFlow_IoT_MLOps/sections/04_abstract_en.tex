\chapter*{ABSTRACT}
\addcontentsline{toc}{chapter}{ABSTRACT}

This work focuses on the development of an IoT MLOps platform for real-time industrial sensor monitoring with machine learning-based anomaly detection.

The relevance of this research stems from the need of industrial enterprises for affordable equipment monitoring solutions. Existing enterprise platforms have high costs and implementation complexity, while open-source solutions require significant effort to integrate components into a cohesive system.

The objective is to create a multi-tenant platform that combines stream data processing, machine learning for anomaly detection, and MLOps practices using open-source technologies.

The research methodology includes analytical methods for studying existing platforms, machine learning methods (Isolation Forest, Random Forest, XGBoost) for anomaly detection, experimental methods for performance testing, and comparative analysis of algorithms.

Key results: a microservices architecture based on Docker was developed; low-latency stream processing through Apache Kafka and Spark was achieved; schema-per-tenant isolation with TimescaleDB compression was implemented; high anomaly detection quality was demonstrated on the Tennessee Eastman Process dataset.

The practical significance lies in creating a production-ready solution for industrial enterprises that enables early detection of equipment failures and reduces costs associated with unplanned maintenance.
