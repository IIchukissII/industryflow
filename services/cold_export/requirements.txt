# Cold-layer exporter runtime (ADR-0025): a single-node columnar writer (decision 11) that reads
# raw measurements from TimescaleDB and writes partitioned Parquet to the object store. No Spark.
# pyarrow provides both the Parquet writer and the S3/MinIO filesystem (pyarrow.fs.S3FileSystem),
# so no separate S3 SDK is needed. psycopg2 matches the pin the streaming/ml images use.
# pyarrow's wheel is compiled against numpy's C ABI, so the two move together: pyarrow 14 was built
# against numpy 1.x and fails to import under numpy 2.x. pyarrow 25 is built against 2.x, which is
# what lets the platform take the numpy-2 major. The Parquet contract is unchanged across the bump
# (format 2.6, zstd, the explicit COLD_SCHEMA) and tests/test_parquet_compat.py holds it to that
# against a file written by the old pin.
numpy>=2.5.1,<3
pyarrow==25.0.0
psycopg2-binary==2.9.12
